Word Wars — Launcher
====================

Keep this. It downloads the game, and every time Damon puts out an update it
picks that up on its own, so you never have to come back for another download.


Run it
------
    Windows:  double-click WordWarsLauncher.exe
              SmartScreen may warn the publisher is unknown — the build is not
              code-signed. Click "More info", then "Run anyway".

    Linux:    chmod +x WordWarsLauncher.x86_64
              ./WordWarsLauncher.x86_64


What it does
------------
Checks GitHub for the newest release, downloads it if yours is out of date,
then starts the game. If there is nothing new it just starts the game.

If you are offline it runs whatever version you already have.

The game itself is kept in the launcher's own data folder, so there is nothing
to install and nothing to tidy up.


Playing a friend
----------------
Press V on the title screen. One of you clicks HOST and gets a room code —
click it to copy, then send it over. The other pastes it with CTRL+V and clicks
JOIN. Everyone readies up. Up to four people per room, and the host can add
CPUs with + to fill the empty seats.

No port forwarding and no IP addresses.
